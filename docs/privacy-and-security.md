# Privacy, Security & Automotive Compliance Protocol

## 1. Regulatory Context

The Vehicle Damage Detection system processes vehicle imagery and onboard diagnostic telemetry. These data streams are subject to privacy regulations (GDPR, CCPA) and automotive safety standards (SAE J2012, NHTSA FMVSS).

---

## 2. PII Redaction & Anonymization

1. **Automatic License Plate & Face Blurring:**
   - Vehicle license plates and visible passenger faces captured in inspection photographs undergo blurring before permanent database storage or model training loops.
2. **VIN Masking Policy:**
   - Vehicle Identification Numbers (VIN) are masked in user-facing views and API responses beyond the first 11 characters (e.g., `1HGCR2F83HA******`), concealing the individual serial number while preserving manufacturer, model, and year decoding.
3. **EXIF Metadata Stripping:**
   - All uploaded images have EXIF metadata (GPS coordinates, camera serial numbers, original timestamps) stripped on ingestion prior to file system persistence.

---

## 3. Storage & Network Security

1. **Path Traversal Protection:**
   - File storage (`backend/app/services/file_storage.py`) sanitizes all original filenames and resolves strictly within configured storage boundaries, preventing directory traversal attacks.
2. **JWT Authentication & Password Hashing:**
   - Passwords are salted and hashed using standard bcrypt (`bcrypt.hashpw` with individual work factors).
   - Session tokens are stateless JSON Web Tokens (HS256) with configurable expiration times (default: 24 hours).
3. **Role-Based Access Control:**
   - Inspectors can only view and manage their own inspection records unless granted organizational administrative credentials.

---

## 4. Legal Decision-Support Boundary

Under ISO 26262 functional safety and consumer protection principles, automated AI vision systems cannot replace physical mechanical roadworthiness inspections.

Every output generated by this application (API JSON, Flutter Mobile UI, Executive PDF Report) carries the mandatory advisory:
> *"Roadworthiness assessments (Safe, Caution, Unsafe) generated by this system are automated recommendations intended exclusively to support trained human examiners. This application does not issue a legally binding guarantee of structural integrity or roadworthiness. Critical vehicle safety systems (braking, airbag SRS, suspension geometry) must always be inspected physically by a certified mechanic."*
